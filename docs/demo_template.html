SANKPUP (from the Thai words "sang phap", make a picture): pictures made purely from code. Here the built-in offline generator writes SVG in your browser (byte-identical to terai sankpup --engine offline); the Python package can also let a local Gemma 4 model write the SVG. No pixel model, no cloud API.

MuML 1.0 WA (MuML 1.0 Web Audio API): music written and played in your browser. A seeded Markov note writer trained on the MuML 1.0 data (Nottingham folk tunes) writes the notes; the Web Audio API synthesizes every sound from oscillators, filters and noise. No soundfont, no server, no cloud API. Same prompt and seed give the same song as terai_router.muml_wa in Python. The note writer is Markov v1, not the trained MuML 1.0 model yet. License: code MIT; the note table (muml_wa_table.js, built from the Nottingham dataset) is GPL-3.0.
